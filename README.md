# Python sorting app

This application was made using pygame.  
I did it while in the hospital and it is a reproduction of some apps you can see on youtube that visually show different sorting algorithms.  
Here is a example photo of how the application looks :

You can change the sorting algorithm using the dropdown menu ; the two text input are here to repectively change the number of bars sorted and adding a delay before each sorting step, you can change their values by clicking on them, deleting the current value, changing it, and applying the new value by pressing enter.
